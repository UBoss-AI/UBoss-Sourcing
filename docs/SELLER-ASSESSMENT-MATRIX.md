# Seller Assessment and Onboarding - requirement matrix

Source: *Seller Assessment and Onboarding Process and Checklist*, Version 1.0, prepared 9 October 2026, effective date blank. Every requirement in its twelve sections, what existed before, what was built, the evidence, and the status.

**Status words.** *Software built* means the software records, enforces or refuses as described and a test proves it. It never means the real-world step happened. *Human action* means people must do it (a visit, a test, an adoption, a signature); the software records it when they do. *Partial* names exactly what is missing.

Tests: `U` = `backend/tests/unit/seller-assessment.test.ts`, `I` = `backend/tests/integration/seller-assessment.test.ts`, `T` = `backend/tests/unit/seller-turnover.test.ts` and `backend/tests/integration/seller-turnover.test.ts`.
